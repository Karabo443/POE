# StudySip Cafe website

This is a self-contained, static website for StudySip Cafe.

## Open the site

Open `index.html` or `Home.html` in a browser. The site uses only files in this folder, plus Google Fonts and the embedded map on the contact page.

## Pages

- `Home.html` — cafe landing page
- `About.html` — cafe background and house rules
- `Menu.html` — JavaScript-rendered searchable and sortable menu
- `Study.html` — study space information
- `Order.html` — order, enquiry and table booking request form
- `Contact.html` — location and general contact form
